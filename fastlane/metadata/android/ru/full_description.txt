Приватный трекер настроения для Android, полностью работающий без сети. Записывайте, как вы себя чувствуете, по своим шкалам, со своими тегами, в свои окна напоминаний и на своём устройстве. Ничего никуда не загружается. Резервные копии, если они нужны, вы делаете сами так, как удобно (подсказка: Syncthing хорошо работает с зашифрованными копиями, которые вы сохраняете).

<b>Возможности</b>

* <b>Свои шкалы.</b> Пять встроенных шкал (Счастье, Тревога, Стресс, Скука, Боль), каждая числовая и со своим цветом. Добавляйте свои и архивируйте ненужные.
* <b>Свои теги.</b> Выбирайте из множества встроенных тегов для мест, людей, занятий, эмоций и не только, или создавайте свои, чтобы настроить записи под себя.
* <b>Окна напоминаний.</b> Задайте периоды дня (например, утро 08:00–12:00, вечер 18:00–20:00). Приложение присылает одно уведомление на каждое окно в день. Нажмите на уведомление, чтобы сразу перейти к новой записи.
* <b>История и графики.</b> Просматривайте прошлые записи и изменения по каждой шкале со временем.
* <b>На вашем языке.</b> Приложение доступно на нескольких языках, включая русский. Язык приложения можно выбрать в настройках, независимо от языка телефона.
* <b>Зашифрованное хранение.</b> База данных хранится в зашифрованном виде с помощью SQLCipher. Ключ находится в памяти только пока приложение разблокировано и стирается при блокировке.
* <b>Блокировка PIN-кодом и биометрией.</b> Вход в приложение по PIN-коду, с необязательной биометрической разблокировкой. Перед сохранением PIN-код хешируется с помощью PBKDF2-HMAC-SHA256 (600 000 итераций).
* <b>Зашифрованные резервные копии.</b> Ручной экспорт сохраняет зашифрованный AES-GCM файл JSON в Documents/MoodCairns/. Ключ шифрования получается из выбранной вами парольной фразы (минимум 8 символов) с помощью PBKDF2-HMAC-SHA256 (600 000 итераций) и новой соли для каждой копии, поэтому любая установка, даже новая, может расшифровать копию той же фразой. Копии из старых версий, зашифрованные PIN-кодом приложения, по-прежнему импортируются с этим PIN-кодом.

<b>Обещание конфиденциальности</b>

Приложение <b>не запрашивает никаких сетевых разрешений</b>. Без доступа к интернету процесс буквально не может открыть соединение, поэтому отправить куда-либо данные невозможно, что бы ни пыталась сделать любая из подключённых библиотек.
Сборка проверяет это автоматически, так что обновление зависимостей никогда не сможет незаметно добавить сетевое разрешение.
Если вы хотите синхронизировать резервные копии с другими устройствами, укажите Syncthing (или любому файловому менеджеру, умеющему синхронизировать папки) папку Documents/MoodCairns/.
